# Análise de Performance - Volkswagen vs Concorrentes

Este projeto realiza uma análise comparativa de performance entre a Volkswagen e seus concorrentes no mercado automotivo, utilizando dados de métricas de SEO e tráfego.

## Requisitos

- Python 3.8 ou superior
- Dependências listadas em `requirements.txt`

## Instalação

1. Clone este repositório
2. Instale as dependências:
```bash
pip install -r requirements.txt
```

## Execução

Para executar o relatório de análise, execute o seguinte comando:
```bash
streamlit run analise_performance.py
```

## Estrutura do Relatório

O relatório está dividido em 6 seções principais:

1. Análise do Tráfego Orgânico Total
2. Análise de Palavras-chave Comerciais
3. Análise da Autoridade do Domínio
4. Análise do Share de Tráfego
5. Análise Comparativa Detalhada
6. Conclusões e Insights

## Dados Analisados

O relatório utiliza os seguintes arquivos JSON:
- `analise_detalhada_recreiovw_por_pagina.json` (Volkswagen)
- `analise_detalhada_carbel_por_pagina.json`
- `analise_detalhada_grupoab_por_pagina.json`
- `analise_detalhada_wtotalvw_por_pagina.json`
- `relatorio_romavw.json`
- `relatorio_servopa.json`
- `relatorio_sagavw.json`
